01 Shipped product, macOS

Crew, a tiny crew of pixel monsters for your Claude Code agents

One creature per chat and subagent, living along the bottom of your screen. A glance tells you which agent is working, which is stuck waiting on you, and which finished ten minutes ago.

Why it exists

Five sessions at once, and all of it invisible

You can run four or five Claude Code sessions at once and none of it shows up anywhere. Reading a dashboard costs a glance, a parse and a context switch. So the state is a creature instead: you notice something is wrong from the corner of your eye, before you have consciously looked at anything.

By the numbers

  • 10species drawn in code
  • 7Claude Code hooks
  • 0servers, accounts or telemetry

The rule it is built on

It never invents a state. Every animation is driven by a real hook event.

03 About

Ravindra Pratap Singh Sisodia

Senior product designer in Bengaluru, five years across B2B SaaS, fintech and enterprise.

I sit on the line between a high fidelity design file and the code that actually ships. Figma for the thinking, Claude Code for the building, SwiftUI and the web for the delivery. When the handoff happens inside one head, fewer decisions get lost on the way to production.

Right now I am becoming an engineer who can also ship the design. That has meant a run of small Mac apps and single file sites built end to end, from the first frame to the release build.

Pixels by day, petrol by dusk.

I grew up in Jodhpur, Rajasthan, which is where the taste for hard light and heavy material comes from. I ride motorbikes to clear my head, usually right after a build finishes.
