How it ships

The launches are the output. The system is the work.

Taste

My own design skill

/rav is a Claude Code skill with a core spec and eight reference playbooks for layout, motion, color and copy. It built this page.

Build

Hooks, not polling

Crew wires Claude Code's UserPromptSubmit, Stop, PreToolUse and SubagentStop events into one shell script, so every agent appears the moment it starts.

Review

Agents that review agents

Notchling's weather scenes went through an eight-agent panel: one subagent per screenshot plus a coherence judge, scoring against a written brief.

Record

Transcripts as data

Chit and my daily worklog read Claude Code's own session transcripts, so the record of what I shipped writes itself every evening.
